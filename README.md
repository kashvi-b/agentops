# AgentOps

A self-testing AI agent platform built with Python, LangGraph, Groq, FastAPI, and Streamlit.

## Project Goal

Build an AI agent that can:
- Plan and execute user tasks
- Use approved Python tools
- Verify execution results
- Recover from failures
- Evaluate agent performance
- Track execution traces and metrics

## Tech Stack

- Python 3.12
- LangGraph
- Groq API
- FastAPI
- Streamlit
- pytest
- SQLite
- Docker
- GitHub Actions

## Development Status

Milestone 1: Project foundation in progress.

## Security

API keys are stored in local environment variables and are never committed to GitHub.
